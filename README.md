# Asterius-Maze Algorithm Simulator

Interactive visualization comparing different pathfinding algorithms (BFS, DFS, Dijkstra) with real-time performance analysis.

## Features
- Interactive visualization of BFS, DFS, and Dijkstra algorithms
- Real-time performance comparison
- Algorithm efficiency analysis across different maze sizes
- Visual representation of search strategies

## Technologies
- Python
- Pygame
- Algorithm visualization
- Real-time performance benchmarking

## How to Run

```bash
git clone https://github.com/moisesupr/Asterius-Maze.git
cd maze-solver
python main.py
```
## Controls
- **Space**: Run BFS algorithm
- **D**: Run DFS algorithm
- **C**: Clear maze
- **R**: Randomize obstacles and end point (red)
- Start point is always at the center

## What I Built
- Interactive maze generator and solver
- Implemented BFS, DFS, and Dijkstra algorithms
- Real-time visualization of algorithm pathfinding
- Performance analysis comparing algorithm efficiency

## Algorithms Compared
- **BFS**: Breadth-first search for shortest path
- **DFS**: Depth-first search exploration
- **Dijkstra**: Optimal pathfinding with weighted costs
